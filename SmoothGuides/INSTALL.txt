  SmoothGuides v1.0 — Panel de Guías para After Effects
══════════════════════════════════════════════════════

REQUISITOS
──────────
• After Effects CC 2021 (v17.5) o superior
• Windows 10/11 o macOS 10.15+

─────────────────────────────────────────────────────
  INSTALACIÓN (Windows)
─────────────────────────────────────────────────────

1. HABILITAR EXTENSIONES NO FIRMADAS
   Abre el Editor de Registro (regedit) y ve a:

   HKEY_CURRENT_USER\SOFTWARE\Adobe\CSXS.11
   (o CSXS.10 / CSXS.9 según tu versión de CEP)

   Crea un valor String llamado:  PlayerDebugMode
   Con el valor:                  1

   Alternativa rápida — ejecuta este comando en PowerShell (Admin):
   Set-ItemProperty -Path "HKCU:\SOFTWARE\Adobe\CSXS.11" -Name "PlayerDebugMode" -Value "1" -Type String

2. COPIAR LA CARPETA
   Copia la carpeta "SmoothGuides" completa a:

   C:\Program Files (x86)\Common Files\Adobe\CEP\extensions\

   O a la carpeta de usuario:
   C:\Users\<TuNombre>\AppData\Roaming\Adobe\CEP\extensions\

3. ABRIR AFTER EFFECTS
   Window → Extensions → SmoothGuides

─────────────────────────────────────────────────────
  INSTALACIÓN (macOS)
─────────────────────────────────────────────────────

1. Habilitar en Terminal:
   defaults write com.adobe.CSXS.11 PlayerDebugMode 1

2. Copiar carpeta a:
   /Library/Application Support/Adobe/CEP/extensions/
   (o ~/Library/Application Support/Adobe/CEP/extensions/)

3. Abrir AE → Window → Extensions → SmoothGuides

─────────────────────────────────────────────────────
  USO BÁSICO
─────────────────────────────────────────────────────

1. Abre una composición en After Effects
2. Selecciona el formato (9:16, 16:9, etc.)
3. Activa las guías que necesitas
4. Pulsa "Aplicar Guías" → se crean en la comp activa
5. Usa "Eliminar Guías" para limpiar
